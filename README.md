## Competition

[Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) — one line, at most 120 characters: the funniest voicemail greeting a cat would record. Winner takes all ($2).

## Entry

> Hi, it's Mittens. I'm busy pushing your vase off the table. Leave a message after the crash.

## Run

`python3 main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline.
